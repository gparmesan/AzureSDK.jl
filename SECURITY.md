# Security policy

## Reporting a vulnerability

Please do **not** report security problems in public issues.

Use GitHub's private reporting instead: open the repository's **Security** tab
and click **Report a vulnerability**. Include the affected version, a
description of the problem and, if possible, steps to reproduce it. Do not
include real credentials, connection strings or SAS tokens; use placeholders.

This is a volunteer project, so responses are best effort. We aim to
acknowledge reports within a week and will coordinate a fix and disclosure
with you.

Vulnerabilities in Azure services themselves, rather than in this package,
should be reported to the
[Microsoft Security Response Center](https://msrc.microsoft.com/).

## Supported versions

Security fixes are made for the latest released version only.
