AzureSDK — Module
AzureSDK

Azure SDK for Julia. Submodules mirror the Python SDK packages:

  • AzureSDK.Identity — azure.identity
  • AzureSDK.EventHubs — azure.eventhub
  • AzureSDK.ServiceBus — azure.servicebus
  • AzureSDK.Storage.Blob — azure.storage.blob
  • AzureSDK.AzureCore — azure.core (credentials, errors, retry options)
  • AzureSDK.AMQP — the AMQP 1.0 protocol engine used by the messaging clients

AzureSDK.AzureCore — Module
AzureSDK.AzureCore

Shared building blocks, modelled on Python's azure.core: credential types, the exception hierarchy, retry options, a small hardened HTTP helper, connection-string parsing and shared access signature generation.

AzureSDK.AzureCore.ItemPaged — Type
ItemPaged{T}

A lazy, iterable collection of T fetched from the service one page at a time (Python: azure.core.paging.ItemPaged). Iterate it directly, collect it, or iterate pages with by_page. Iterating again starts over with fresh requests.

AzureSDK.AzureCore.PageIterator — Type
PageIterator{T}

Iterator over the pages (Vector{T}) of an ItemPaged. Its continuation_token field holds the token for the page after the last one returned (or nothing when there are no more pages), so a listing can be resumed later with by_page(paged; continuation_token=token).

AzureSDK.AzureCore.RetryOptions — Type
RetryOptions(; retry_total=3, retry_backoff_factor=0.8, retry_backoff_max=120, retry_mode=RetryMode.Exponential)

Retry policy for transient failures. With exponential back-off the delay before retry n (1-based) is retry_backoff_factor * 2^(n-1) seconds (with ±20 % jitter), capped at retry_backoff_max.

Shared messaging types

Types used by both Event Hubs and Service Bus (re-exported by both modules).

AzureSDK.Messaging — Module
AzureSDK.Messaging

Internal infrastructure shared by AzureSDK.EventHubs and AzureSDK.ServiceBus: transport selection, connection strings, credentials to CBS token providers, AMQP error classification and the retry loop.

source
AzureSDK.Messaging.TransportType — Module
TransportType.Amqp / TransportType.AmqpOverWebsocket / TransportType.Http

How a client talks to the service:

  • Amqp: AMQP 1.0 over TLS on port 5671 (default; best performance).
  • AmqpOverWebsocket: AMQP 1.0 tunnelled through a WebSocket on port 443 (works through firewalls/proxies that only allow HTTPS; supports http_proxy).
  • Http: the services' REST APIs over HTTPS. Only a subset of operations is available (sending, and for Service Bus basic receive/settle); this is an extension not present in the Python SDK.
source
AzureSDK.Messaging.AmqpAnnotatedMessage — Type
AmqpAnnotatedMessage

Alias of AzureSDK.AMQP.AMQPMessage (Python: azure.core.amqp.AmqpAnnotatedMessage): a raw AMQP message with full control over header, annotations, properties and body. Can be sent with send_messages, add_message!, send_event and add!.
