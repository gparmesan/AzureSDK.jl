Blob Storage API

AzureSDK.Storage — Module
AzureSDK.Storage

Azure Storage clients, mirroring Python's azure.storage.* packages:

  • AzureSDK.Storage.Blob — azure.storage.blob

Shared pieces (Shared Key signing, the retrying HTTP pipeline, error mapping, XML handling) live in this module.

source
AzureSDK.Storage.Blob — Module
AzureSDK.Storage.Blob

Azure Blob Storage client modelled on Python's azure.storage.blob: BlobServiceClient, ContainerClient, BlobClient and BlobLeaseClient; block, page and append blobs; parallel chunked uploads and downloads (StorageStreamDownloader); snapshots, versions, tags, tiers, copies, leases, batch operations and shared access signatures. Authentication: Shared Key (account key), SAS, Microsoft Entra ID (TokenCredential, e.g. workload identity) or anonymous.

AzureSDK.Storage.Blob.BlobServiceClient — Type
BlobServiceClient(account_url; credential=nothing, kwargs...)
BlobServiceClient(f::Function, account_url; kwargs...)      # do-block form
from_connection_string(BlobServiceClient, conn_str; credential=nothing, kwargs...)

Client for the Blob service of a storage account (Python: azure.storage.blob.BlobServiceClient). account_url is https://<account>.blob.core.windows.net (optionally with a SAS query string). credential may be nothing (anonymous or SAS in the URL), a SAS token string, an account key string, an AzureNamedKeyCredential, a dict / named tuple with account_name and account_key, an AzureSasCredential or any TokenCredential (e.g. DefaultAzureCredential()).

Keyword arguments: api_version, audience, connection_timeout (20 s), read_timeout (60 s), retry_total (3), retry_backoff_factor, retry_backoff_max, retry_mode, connection_verify, http_proxy, user_agent, max_single_put_size (64 MiB), max_block_size (4 MiB), max_page_size (4 MiB), max_single_get_size (32 MiB) and max_chunk_get_size (4 MiB).

Properties: url, account_name, primary_endpoint, primary_hostname, credential, api_version.

AzureSDK.Storage.Blob.download_blob — Method
download_blob(blob_client; offset=nothing, length=nothing, version_id=nothing, validate_content=false,
              max_concurrency=1, encoding=nothing, lease=nothing, etag=nothing, match_condition=nothing,
              if_modified_since=nothing, if_unmodified_since=nothing, if_tags_match_condition=nothing,
              cpk=nothing, progress_hook=nothing, timeout=nothing) -> StorageStreamDownloader

Start downloading the blob (or the byte range offset, length). The first max_single_get_size bytes (32 MiB) are fetched immediately; the rest in max_chunk_get_size chunks (4 MiB), max_concurrency at a time, pinned to the blob's ETag so a concurrent modification is detected (ResourceModifiedError) instead of producing a torn read. With validate_content=true every chunk's MD5 is checked. With encoding ("UTF-8") readall returns a String.

AzureSDK.Storage.Blob.upload_blob — Method
upload_blob(blob_client, data; blob_type=BlobType.BLOCKBLOB, length=nothing, metadata=nothing, overwrite=false,
            content_settings=nothing, validate_content=false, max_concurrency=1, tags=nothing,
            standard_blob_tier=nothing, premium_page_blob_tier=nothing, maxsize_condition=nothing,
            lease=nothing, etag=nothing, match_condition=nothing, if_modified_since=nothing,
            if_unmodified_since=nothing, if_tags_match_condition=nothing, cpk=nothing, encryption_scope=nothing,
            immutability_policy=nothing, legal_hold=nothing, progress_hook=nothing, timeout=nothing) -> Dict

Upload data (bytes, a string or any IO, e.g. an open file) as a block, page or append blob.

  • Block blobs up to max_single_put_size (64 MiB) are uploaded with a single request; larger or unknown-length data is split into blocks of max_block_size (4 MiB) that are uploaded max_concurrency at a time and then committed.
  • Page blobs need a known length that is a multiple of 512; all-zero pages are skipped.
  • Append blobs are created when missing (or replaced with overwrite=true) and the data is appended.

Without overwrite=true an existing blob raises ResourceExistsError (block and page blobs). progress_hook(current, total) is called as data is sent. Returns etag, last_modified and the other response properties.
