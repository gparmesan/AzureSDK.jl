Service Bus API

AzureSDK.ServiceBus — Module
AzureSDK.ServiceBus

Azure Service Bus client modelled on Python's azure.servicebus: ServiceBusClient, ServiceBusSender, ServiceBusReceiver, sessions, scheduling, deferral, dead-lettering, peeking and automatic lock renewal. Transports: AMQP over TLS, AMQP over WebSockets, and HTTP (REST; a subset of operations).

source
AzureSDK.ServiceBus.NEXT_AVAILABLE_SESSION — Constant

Pass as session_id to receive from the next available session.

source
AzureSDK.ServiceBus.AutoLockRenewer — Type
AutoLockRenewer(; max_lock_renewal_duration=300, on_lock_renew_failure=nothing)

Keeps message or session locks alive in the background. Register targets with register!, or pass the renewer as auto_lock_renewer when creating a receiver to register every received message (or the session) automatically.

on_lock_renew_failure(target, error) is called when renewal fails.

source
AzureSDK.ServiceBus.ServiceBusClient — Type
ServiceBusClient(fully_qualified_namespace, credential; kwargs...)
ServiceBusClient(f::Function, args...; kwargs...)   # do-block: closes the client afterwards

Entry point for Service Bus (azure.servicebus.ServiceBusClient). Create senders and receivers with get_queue_sender, get_queue_receiver, get_topic_sender and get_subscription_receiver. All handlers created from one client share a single connection.

Keyword arguments: transport_type (TransportType.Amqp, TransportType.AmqpOverWebsocket or TransportType.Http), http_proxy, custom_endpoint_address, connection_verify, retry_total (3), retry_backoff_factor (0.8), retry_backoff_max (120), retry_mode, auth_timeout (60 s), user_agent.

AzureSDK.ServiceBus.ServiceBusReceivedMessage — Type
ServiceBusReceivedMessage

A message received from a queue or subscription. Besides the fields of ServiceBusMessage it exposes sequence_number, enqueued_sequence_number, enqueued_time_utc, locked_until_utc, lock_token, delivery_count, dead_letter_reason, dead_letter_error_description, dead_letter_source, state, expires_at_utc and raw_amqp_message.

source
AzureSDK.ServiceBus.ServiceBusReceiver — Type
ServiceBusReceiver

Receives messages from a queue or subscription. Create with get_queue_receiver or get_subscription_receiver. Iterating over a receiver yields messages until max_wait_time passes without a new message (or forever when max_wait_time is nothing).

source
AzureSDK.ServiceBus.ServiceBusSender — Type
ServiceBusSender

Sends messages to a queue or topic. Create with get_queue_sender or get_topic_sender.

source

ServiceBusSession

The session a session receiver is locked to (receiver.session). Fields: session_id, locked_until_utc. Operations: get_state, set_state, renew_lock.

AzureSDK.ServiceBus.receive_messages — Method
receive_messages(receiver; max_message_count=1, max_wait_time=nothing) -> Vector{ServiceBusReceivedMessage}

Receive up to max_message_count messages. Waits up to max_wait_time seconds (default: the receiver's max_wait_time; wait indefinitely if both are nothing) for the first message, then briefly for more.
