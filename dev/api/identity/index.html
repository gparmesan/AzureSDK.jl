Identity

AzureSDK.Identity — Module
AzureSDK.Identity

Microsoft Entra ID credentials modelled on Python's azure.identity: DefaultAzureCredential, ChainedTokenCredential, EnvironmentCredential, WorkloadIdentityCredential, ManagedIdentityCredential, ClientSecretCredential, ClientCertificateCredential, ClientAssertionCredential, AzureCliCredential and AzureDeveloperCliCredential.

All credentials are thread-safe, cache tokens in memory and refresh them ahead of expiry. Secrets are never included in show output, logs or error messages.

AzureSDK.Identity.ChainedTokenCredential — Type
ChainedTokenCredential(credentials...)

Try each credential in order. A CredentialUnavailableError moves on to the next credential; any other failure stops the chain and raises a ClientAuthenticationError.

Authenticate a service principal with a certificate. The certificate can be a PEM file containing the certificate and its (optionally encrypted) private key, or a PKCS#12 (.pfx) file. Client assertions are signed with RS256.

AzureSDK.Identity.CredentialUnavailableError — Type
CredentialUnavailableError(message)

The credential cannot attempt authentication in this environment (e.g. the required environment variables are missing, or the Azure CLI is not installed). ChainedTokenCredential moves on to the next credential when it sees this error.

source
AzureSDK.Identity.EnvironmentCredential — Type
EnvironmentCredential()

Configured from environment variables:

  • service principal with secret: AZURE_TENANT_ID, AZURE_CLIENT_ID, AZURE_CLIENT_SECRET
  • service principal with certificate: AZURE_TENANT_ID, AZURE_CLIENT_ID, AZURE_CLIENT_CERTIFICATE_PATH, optionally AZURE_CLIENT_CERTIFICATE_PASSWORD and AZURE_CLIENT_SEND_CERTIFICATE_CHAIN
  • optional: AZURE_AUTHORITY_HOST, AZURE_ADDITIONALLY_ALLOWED_TENANTS (;-separated)

Username/password authentication is not supported (Microsoft has deprecated it; it does not work with multi-factor authentication).

source
AzureSDK.Identity.ManagedIdentityCredential — Type
ManagedIdentityCredential(; client_id=nothing, object_id=nothing, resource_id=nothing)

Authenticate with an Azure managed identity. Pass one of client_id, object_id or resource_id for a user-assigned identity; omit all three for the system-assigned identity. The hosting environment is detected from environment variables, like the Python SDK.

source
AzureSDK.Identity.WorkloadIdentityCredential — Type
WorkloadIdentityCredential(; tenant_id=ENV["AZURE_TENANT_ID"], client_id=ENV["AZURE_CLIENT_ID"],
                           token_file_path=ENV["AZURE_FEDERATED_TOKEN_FILE"], authority=nothing,
                           additionally_allowed_tenants=String[])

Microsoft Entra Workload ID (e.g. on Azure Kubernetes Service): exchanges the projected service account token in token_file_path for an access token. The file is re-read at most every 5 minutes so rotated tokens are picked up.

source
AzureSDK.Identity.DefaultAzureCredential — Method
DefaultAzureCredential(; exclude_environment_credential=false,
                       exclude_workload_identity_credential=false,
                       exclude_managed_identity_credential=false,
                       exclude_cli_credential=false,
                       exclude_developer_cli_credential=false,
                       managed_identity_client_id=ENV["AZURE_CLIENT_ID"],
                       workload_identity_client_id=ENV["AZURE_CLIENT_ID"],
                       workload_identity_tenant_id=ENV["AZURE_TENANT_ID"],
                       authority=nothing, process_timeout=10,
                       additionally_allowed_tenants=String[])

The default credential chain, in the same order as the Python SDK:

  1. EnvironmentCredential
  2. WorkloadIdentityCredential (if its environment is configured)
  3. ManagedIdentityCredential
  4. AzureCliCredential
  5. AzureDeveloperCliCredential

Set AZURE_TOKEN_CREDENTIALS=dev (developer tools only), prod (environment, workload identity, managed identity only), or the name of one credential (e.g. ManagedIdentityCredential) to restrict the chain. Once a credential succeeds it is used for all later requests.
