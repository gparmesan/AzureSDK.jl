AMQP

The AMQP 1.0 engine used by the Event Hubs and Service Bus clients.

AzureSDK.AMQP — Module
AzureSDK.AMQP

A pure-Julia AMQP 1.0 client: type codec, framing, SASL, connection / session / link state machines with flow control, request/response management links, claims-based security, and TCP / TLS / WebSocket transports.

This module is the protocol engine behind AzureSDK.EventHubs and AzureSDK.ServiceBus; it can also be used directly against any AMQP 1.0 broker.

source
AzureSDK.AMQP.AMQPArray — Type
AMQPArray(elements::AbstractVector)

Wrapper that forces a Julia vector to be encoded as an AMQP array (all elements share one constructor) instead of an AMQP list. Several Azure management operations require arrays, e.g. lock-tokens (array of uuid) or sequence-numbers (array of long).

AzureSDK.AMQP.AMQPDescribed — Type
AMQPDescribed(descriptor, value)

A described value whose descriptor is not one of the composite types known to this implementation (for example a filter such as apache.org:selector-filter:string).

AzureSDK.AMQP.AMQPException — Type
AMQPException(scope, condition, description; info=nothing, cause=nothing)

Error raised by the AMQP layer. scope is one of :connection, :session, :link, :delivery, :transport, :timeout or :protocol; condition is the AMQP error condition symbol (e.g. Symbol("amqp:not-found")).

source
AzureSDK.AMQP.AMQPMessage — Type
AMQPMessage

A bare AMQP 1.0 message with all standard sections.

body_type is one of :data (body::Vector{Vector{UInt8}}, one entry per data section), :value (body is any AMQP value) or :sequence (body::Vector{Vector{Any}}, one entry per amqp-sequence section).

Annotation maps use Symbol keys (AMQP symbols); application properties use String keys.
