AzureSDK.jl

A pure-Julia client library for Azure Event Hubs, Azure Service Bus, Azure Blob Storage and Microsoft Entra ID authentication. Its structure and API follow the official Azure SDK for Python (azure-eventhub, azure-servicebus, azure-storage-blob, azure-identity, azure-core).

  • AMQP 1.0 over TLS (port 5671), AMQP over WebSockets (port 443, proxy support) and HTTP/REST transports
  • Shared access keys / signatures and Entra ID tokens (workload identity, managed identity, service principals, Azure CLI, …) with automatic token refresh
  • Automatic reconnection and retries with exponential back-off
  • Written in Julia (no Python or C SDK underneath); TLS via Reseau.jl, HTTP and WebSockets via HTTP.jl
Note

This is an independent community project. It is not an official Microsoft product and is not affiliated with or endorsed by Microsoft.

Installation

using Pkg
Pkg.add("AzureSDK")        # before registration: Pkg.add(url="<repository url>")

Julia 1.10 or newer is required.

Not implemented (yet)

Service Bus and Event Hubs administration clients (creating queues, topics, hubs), the Event Hubs buffered producer and idempotent publishing, AMQP transactions, Kafka, the interactive / device code / PowerShell / VS Code credentials and Service Fabric managed identity. For Blob Storage: client-side encryption, query_blob, CRC64 content validation and reads from the secondary endpoint.
